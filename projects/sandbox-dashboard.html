欢迎使用AI沙箱 Sandbox

AI沙箱平台是面向AI Agent的一站式执行环境平台，为智能体提供安全、隔离、可管理的代码运行能力。平台覆盖代码沙箱、桌面沙箱、浏览器沙箱三大应用场景，支持 Python、JavaScript 等多语言执行，内置资源隔离、网络隔离等多层安全防护，并配齐权限管控与操作审计体系。

常见问题

如何申请沙箱配额？

当现有配额不足时，请联系资源组管理员提交沙箱配额申请，并说明实例数量及资源需求。

遇到invalid API format怎么办？

请检查请求地址、请求方法、请求头和参数格式，确认API版本与示例保持一致后重试。

沙箱网络如何打通？

请先在网络策略中配置访问终端节点服务或经典网络的访问规则，再在创建实例时选择对应策略。
